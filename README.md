# Weekly Study Hours Calculator

A small Python script I built in Week 1 of my AI Developer bootcamp.

## What it does

Given a list of study hours for each day of the week, it calculates:

- Total hours studied
- Daily average
- The day with the most study hours

## How to run

Run this command in the terminal: `python study_hours.py`
